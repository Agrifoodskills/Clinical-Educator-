--- slide
id: ce02-02
layout: Comparison
title: Telling vs exploring
left_head: "Telling"
left:
  type: ul
  color: accent2
  items:
    - Teacher lists errors
    - Learner defends
    - Ends when the list ends
    - "*Feels efficient, changes little*"
right_head: "Exploring"
right:
  type: ul
  color: accent1
  items:
    - Learner self-assesses first
    - Teacher adds what's missed
    - Ends with a commitment
    - "*Slower, and it sticks*"
notes: |
  Run the same scenario both ways as a role-play before showing this
  slide; let the group name the difference themselves.

--- slide
id: ce02-03
layout: Full
title: The feedback conversation
full:
  type: ol
  items:
    - text: Ask first
      items:
        - '"How do you think that went?"'
    - text: Reinforce what was right
      items:
        - Specific, not "good job"
    - text: Add ONE correction
      items:
        - The one that matters most today
    - text: Close on a commitment
      items:
        - '"What will you do differently next time?"'
notes: |
  Four steps, learner speaks first and last. Practice in pairs with the
  ward-round scenario cards.
develops: [CE3, CE4]
